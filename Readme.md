# OverWorld-Item

A spin-off series from the main *OverWorld* project.
Following the official development trajectory of *Minecraft*, this series uses orchestral music to reimagine the history of the game’s blocks—from their material properties to their physical evolution.

Style: Classical / Orchestral / Algorithmic Composition
